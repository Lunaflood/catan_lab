# 交易の相手評価と提案回数

調査日: 2026-09-10。CPU v4（さいきょう）。

## 相手の利益をどう評価しているか

自分の資源枚数だけでは判断していない。

1. `trade.rs::swap_delta` は交換前後の両者の手札の価値を比較する。建築費用を揃える効果や相手の脅威度を評価する。
2. `best_acceptor` は相手の立場で同じ手札評価を計算し、相手に利益があると予測する提案を成立候補にする。候補が複数なら脅威が低い相手を選ぶ。相手の完全な先読みを再実行しているわけではないので、承諾保証ではない。
3. v4 の手番探索では、成立した資源配分から自分の建築などの続き手を比較し、相手側の建築・拡張・最大騎士力などの見込みも評価する。
4. `agent_v2.rs` は提案・承諾・対案・最終成立選択の各段階で、交換が相手の当手番または次手番の勝利確率をどれだけ増やすかを推定し、20,000 倍の係数で減点する。これは内部評価値の係数で、パーセントや勝率の実測値ではない。
5. 非公開の手札・発展カードは観測からの推定。秘密情報の正解を読んで評価する方式ではない。

目標は自分の勝利につながる交換。相手にも得があることと、その相手を勝たせてしまわないことの両方を見る。自分が 2 枚得して相手が 1 枚得する、といった枚数差だけでは決めない。

## 現在の回数制限

`GameConfig::default().max_offers_per_turn` は **3**。

- 1 プレイヤーの手番全体を通じた、新規 `OfferTrade` の数。相手ごとの 3 回ではない。
- 成立しても回数は戻らない。建築や銀行との交換を挟んでも同じ手番内なら通算。
- 銀行・港との海上交易は含まない。
- 承諾・拒否・対案は新規提案の回数に含まない。CPU の対案は 1 つの元提案に対する返答として処理される。
- 上限は候補の自動生成に対する制限で、人間の自由入力に対するカタンのルールではない。
- 誰も応じなかった条件と取り下げた条件はその手番では再生成しない。
- 元提案 1 つにつき他の全プレイヤーに応答を求める。UI は順番が来る前の回答を預かれ、特定相手の提案を自動拒否する設定もある。

1 人間＋3 CPU の 4 人戦なら、全 CPU が上限まで提案する 1 周に、新規提案は上限 2 で最大 6 件、上限 3 で最大 9 件。実際のクリック数は自動拒否や UI 操作によって変わる。

## 実験方法

[事前設計](registration.md) と [再現スクリプト](compare.py) を参照。追加した `catan match --max-offers N` で全席の提案上限だけを変える。計測に必要な件数を自動対戦ハーネスへ追加した。

上限別に 4 人戦 48 局・3 人戦 24 局、全席 v4。合計 288 局。全条件で共通の seed 群を使うが、行動が分岐すると乱数消費も変わる。

全員の制限を変える比較なので、この実験から特定 CPU の勝率の優劣は判定できない。成立数・交渉量・手番数でゲーム進行との釣り合いを見る。人間の満足度や回答にかかる秒数は測っていない。

## 検証

- 交易評価の既存テスト 7 件と手番探索の既存テスト 7 件が成功。
- 各条件で、順番別提案数の合計＝全提案数、順番別成立数の合計＝全成立数、返答数＝提案数×相手人数を照合する。
- CLI の release ビルド成功。Web の設定や CPU の判断ロジックはこの調査では変更しない。

## 推奨

**4 人戦は各 CPU の 1 手番につき新規提案 2 回、3 人戦は 3 回**を推奨する。

- 4 人戦: 3 → 2 回で提案を 13.6% 減らせた。成立の減少は 5.7%、総手番数は 1.2% 増。1 回まで絞ると、既定 3 回より成立が 19.8% 減り、手番数も 8.6% 増えた。
- 3 人戦: 3 → 2 回では提案が 17.9% 減る一方、成立も 15.7% 減るため、交易機会の損失が比較的大きい。3 回を残す。5 回に広げた条件は提案が増えたが、今回の標本では成立件数の改善が見られなかった。
- 人間 1 人の場合、4 人戦は CPU 3 体 × 2 回、3 人戦は CPU 2 体 × 3 回で、いずれも 1 周最大 6 件になる。これは上限の計算であり、人間との対戦での平均提案数を測った値ではない。

同一人数内の全 CPU の上限を変えた、小規模な自己対戦の平均に基づく推奨。これが勝率を最大化する回数である、あるいは人間の満足度の統計的な最適点であるとは判定していない。3 回目にも成立する交渉があるため、2 回への変更には交易機会を一部手放す代価がある。
