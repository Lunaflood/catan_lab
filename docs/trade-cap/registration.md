# 交易提案回数の比較（事前設計）

2026-09-10。製品の標準値は 3 のまま。評価に必要な CLI オプションと計数だけ追加する。

- CPU は全席 v4。上限 1 / 2 / 3 / 5 回を比較。
- 各条件 4 人戦 48 局（seed 10020000〜10020047）、3 人戦 24 局（10030000〜10030023）、合計 288 局。
- 各条件で同じ初期 seed 群、手番制限は既定 120 秒の仮想時計。上限以外は共通。
- 提案数、成立数（対案経由を含む）、手番数、提案の順番別成立数、応答数を集計。
- 対案・承諾・拒否は新規提案数に加算せず、元の提案の順番に帰属させる。
- 成立後の追加提案も数える。第 2 回以降が常に拒否後の再交渉とは限らない。
- 全席共通の制限なので勝率による CPU 強度比較ではない。人間の応答時間・満足度は測定していない。
- 同一 seed でも行動が分岐すると乱数の消費は変わる。同一出目の固定再生ではない。
- 事前に選好する目標は、成立機会を大きく落とさず、人が応答する交渉を減らすこと。回数の厳密な最適性は主張しない。
