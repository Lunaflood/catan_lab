# CPU再監査・強化（2026-09-07）

採用: **2手読み・推定3通り**。公平性修正済みの旧方式3体に対して、別条件の2400局ずつで **27.3% / 26.6%**（計4800局で約27%、同程度なら25%）。13種類の強化候補を比較し、今回のCLI比較は合計21,360局、すべて決着した。

比較開始時のコミット: `5ca9b70d54830ce88664628d5957f6ee6a23d673`。
既存のUIやColonist調査ファイルは変更せず、CPU・情報境界・WASMを更新した。

## 公平性の修正

- `View::hand(player)` と手札を覗く `determinize_with(false)` / `bestcheat` を削除。自分の資源は `my_hand()` のみ。
- シミュレーションのダイス・発展・盗みのRNGを、推論専用RNGから生成し直す。本番の未来の乱数状態を返さない。
- Web/オンラインのCPU初期化にも本番のdice seedを渡さない。座席ごとの定数から推論RNGを初期化する。
- 公開された対案は1本だけでなく全候補を満たすように推定する。同じ資源は代替候補間で共有できるため、合計でなく資源ごとの最大値を確保する。
- 承諾した相手が支払う資源も推定で確保する。推定に失敗した際に実手札を残すフォールバックを除去した。

銀行の内訳はこのアプリで公開されている状態情報として扱う。相手への秘密の盗みは、その相手間での資源の分配が不明になるものとして扱う。

## 強化

最高難易度は、調整済みの評価関数と初期配置評価を維持し、2手読みを3通りの推定手札で比較する。

- 最初の推定だけで候補を落とさず、各推定で残る候補の和集合を使う。
- 根の候補ごとに同じ探索予算を割り当てる。後から列挙された候補だけ浅くなる偏りを避ける。
- CLIの `baseline` / 従来の `best` は比較用の旧探索方式（公平性修正は共通）。`max` は現在の製品版。`bestw3` は採用候補を再現できる。

## 比較条件

4人戦。候補1体対、公平性を修正済みの従来最高難易度3体。交易あり、交渉の時間制限なし。24通りの座席順を巡回。勝率の基準は25%。

修正前の秘密情報の問題を含むバイナリへの比較ではなく、同じ情報制限を適用した探索方式間の比較である。人間やColonist CPUに対する勝率ではない。

### 先読み候補

| 候補 | 一次比較480局 (seed 420000) | 別条件2400局 (seed 610000) |
|---|---:|---:|
| 2手・推定3通り | 26.9% | 27.3% |
| 2手・推定8通り | 25.0% | — |
| 3手・推定1通り | 28.5% | 27.3% |
| 3手・推定3通り | 21.9% | — |

推定3通りと3手読みの2400局での標準誤差はいずれも約0.9ポイント。推定3通りの方がこの測定では短時間で終了した。一次比較だけでの採用はしていない。

### 評価関数の再確認

seed 850000で各480局。`hand_synergy=45/180`、`trade_cost=10`、`buildable_nodes=400`、`afford_city=1.2`も含め8候補を比較した。

| 変更 | 一次比較480局 | 別条件2400局 (seed 970000) |
|---|---:|---:|
| army=24 | 30.0% | 22.958% |
| production=600 | 28.958% | 23.917% |
| enemy_production=-40 | 28.542% | 23.625% |

3変更の組合せも一次比較28.542%にとどまった。個別の改善が再現しなかったため、重みの変更は採用しない。

### 最終の別条件検証

`w3-holdout.txt`: seed 1200000、2400局で26.6%、標準誤差約0.9ポイント、全局決着。
前の2400局と合わせると約27%（通常の二項近似の95%区間は概算25.7〜28.2%）。最終2400局だけでは95%区間が25%を含むため、それ単独で有意な改善と断言しない。候補選択を伴う実験であり、あらゆる相手や条件に対して強いことを証明するものではない。

## 限界

常に最適な手を保証するものではない。自分の手番内の限定探索・有限個の推定・候補削減を行う。相手の手番までの探索、公開履歴を蓄積する手札推定、任意の数量の交易をすべて検討する機能は未実装。今回の比較で確認できる範囲の改善として扱う。

測定コマンドと出力はこのディレクトリの各 `.txt` に保存。`screen_weights.py` は重み一次比較の再実行用。`smoke_wasm.mjs` はWebビルドの動作確認用。
