# M2: 購入世代・制約付き推定・保持／使用機会モデル（実装済み）

## 構成

`crates/catan-ai/src/belief/mod.rs`（粒子フィルタ）, `belief/reach.rs`（勝利ハザード、M3）, `opponent/mod.rs`（使用確率 q）, `history.rs`（公開台帳）。

### 粒子は資源と発展で別々（Rao-Blackwell 化）

- `res: Vec<ResParticle>`: 全員の資源手札（自分の分は正確）。
- `dev: Vec<DevParticle>`: 全員の発展カード（購入世代 `Cohort{bought_turn, own_turns, cards[5]}`）、山の内訳、相手の傾向 θ（4 型）。
- 既定 256 本ずつ。ESS が半分を切ったら系統再サンプル（重み 0 の粒子は選ばない）。
- 完全情報の世界は `(資源, 発展)` を独立に 1 本ずつ引いて作る（`materialize`）。
- **なぜ分けたか**: 最初は 1 粒子に同居させていた。独占の「各人が渡した枚数」照合など資源側の硬い証拠で粒子が数本まで絞られると、発展側の多様性も巻き添えで失われ、校正で「全粒子が同じ札を決め打ち（予測 P(VP≥1)=0.02、実際 0.84）」が出た。分離後は同じ指標が 0.35 まで下がり、Brier が 0.2775 → 0.2465 に改善した。

### 更新規則（設計書 5.2 の表に対応）

| 出来事 | 資源粒子 | 発展粒子 |
|---|---|---|
| 産出・初期配置の資源 | 公開の枚数を加算 | — |
| 建設・購入・銀行交換 | 代金を引く。払えない粒子は重み 0 | 購入: 本人なら種類で条件付け、相手なら粒子の山から抽選して世代に積む |
| 公開交易（成立） | 両者の手札を動かす。持たない粒子は重み 0 | — |
| 提案・承諾・対案・候補 | 「その札を持つ」硬い制約（ルールが検証しているため） | — |
| 拒否 | 何もしない（「持っていない」とは確定しない） | — |
| 第三者の盗み | 被害者の粒子内の手札比で 1 枚移す。実際の種類は参照しない | — |
| 自分が当事者の盗み | 知らされた種類で条件付け | — |
| 独占 | 各人の枚数が公開値と違う粒子は重み 0 | 使用として処理 |
| 廃棄（公開） | 引く | — |
| 発展の使用 | — | 買った手番以外の世代から**確率的に 1 枚選ぶ**（世代を決め打ちしない）。無い粒子は重み 0。相手なら `q` を掛ける |
| 手番終了（相手） | — | 使える札（買った手番の世代を除く）があるのに使わなかった尤度 `1 − max_c q(c, x, d, θ)` を掛ける |
| どの出来事の後でも | — | 手番プレイヤーが勝っていない ⇒ その人の伏せ VP ≤ 9 − 公開点（`check_win` が手番プレイヤーにだけ走るため、そのタイミングだけ） |

- 全滅時は `rebuild_res` / `rebuild_dev` が**公開台帳と枚数だけから**作り直し、発展側は台帳の不使用の尤度を掛け直す（`reweight_dev_from_history`）。本番の手札には戻らない。
- 自分の手札・自分の札は「影」で常に追う（死んだ粒子から写して壊れた、を経験済み）。

### 使用確率 `q(c, x, d, θ)`（`opponent/mod.rs`）

`d` = 買った次の手番を 1 とする本人の手番数、`x` = 公開の使用機会、`θ` = 傾向（早め／標準／温存／無作向、事前 0.35/0.35/0.15/0.15、倍率 1.0/0.8/0.45/0.6）。床 0.03・天井 0.97。ルール上使えない時（道が置けない街道・銀行が空の収穫・勝利点）だけ 0。

`catan v2-fit --games 120 --seed 6000000`（凍結した対照 v2_control×4、採点器が正解を読む）の実測:

| 種類 / 機会 | 機会 | 使用 | 使用率 |
|---|---:|---:|---:|
| 騎士 普通 | 507 | 399 | 0.787 |
| 騎士 盗賊に塞がれ | 558 | 537 | 0.962 |
| 騎士 騎士力が取れる | 220 | 220 | 1.000 |
| 街道建設 普通 | 222 | 107 | 0.482 |
| 街道建設 最長路レース | 84 | 81 | 0.964 |
| 収穫 | 212 | 203 | 0.958 |
| 独占 | 204 | 194 | 0.951 |

保持した手番数別（騎士）: 1 → 0.934, 2 → 0.836, 3 → 0.719, 4 → 0.600, 5+ → 0.500。街道建設: 0.793, 0.308, 0.370, 0.231, 0.207。
採用した既定値は `OpponentParams::default()`（早め型 = 実測に近い値。他の型は倍率）。**人間の値ではない**。

## 校正（`catan v2-calib --games 120 --seed 5000000 --particles 256`、対照 v2_control×4、全 4 席が受動的に推定）

隠れ勝利点の予測 63,069 件（相手が発展カードを 1 枚以上持つ手番終了時）。Brier は 6 クラス分布の二乗誤差、log loss は正解確率の −log。

| 版 | 履歴なし（超幾何） | 保持期間だけ | 使用機会あり | 相手傾向もあり（既定） |
|---|---:|---:|---:|---:|
| 同居粒子・平坦 q（初版） | 0.6250 / 1.299 | 0.2860 / 0.601 | 0.2775 / 0.627 | 0.3367 / 0.735 |
| 分離粒子・平坦 q | 0.6020 / 1.070 | 0.2627 / 0.500 | 0.2465 / 0.475 | 0.2948 / 0.586 |
| **分離粒子・期間つき q（最終）** | 0.6065 / 1.108 | 0.2554 / 0.499 | **0.2493 / 0.468** | 0.3127 / 0.627 |

（Brier / log loss。参考: 一様 1/6 は 0.833、常に 0 は 1.534）

- 「使用機会あり」が最良。「相手傾向もあり」は温存型に質量を残すぶん、この母集団（早めに使う CPU）では**わざと**控えめ = 過信を抑える代償。人間相手にはこちらの方が安全と考え既定にしている（設計書 6.2 の趣旨）。母集団に合わせるなら `features_only`。
- 発展 1 枚保持: 期待 VP 0.600 / 実際 0.650。2 枚: 1.396 / 1.487（履歴なしは 0.381 / 0.650, 0.986 / 1.487 と大きく過小）。
- 相手の資源手札: 正解の手札に置いた確率の平均 **0.886**、期待枚数の平均絶対誤差 0.045 枚。産出・建設・交易・独占が公開なので、盗みの後だけ割れる。
- 勝利ハザード（相手が次の自分の手番で勝つ）18,636 件: Brier 0.048（基準率 0.076 を常に出すと 0.071）。0.9〜1.0 の区間で実際 0.85（過大: 最長路を本数で数える近似・相手が最善を指さない）。0.0〜0.1 で 0.033（過小: 交易や他人の産出を見ない）。
- 診断: 観測不整合 0（自己検査を全出来事で通した）、全滅→組み直し 70/120 局（4 席合計）、最小 ESS 7.8、1 出来事の更新 6 µs、ハザード 1 回 0.27〜0.57 ms。

残る弱点: 0.0〜0.1 の区間で実際 0.35（1,239 件）。5 枚の勝利点が「長く持っている別の相手」に割り当てられ、他の保持者の VP 確率が押し下げられる型。

## テスト（`crates/catan-ai/tests/belief_v2.rs`、設計書 6.6 の 1〜8）

1. 追加情報がなければ超幾何分布と一致（4096 粒子、誤差 < 0.03）。買った当日の EndTurn では分布が動かない。
2. 有効な機会の不使用でだけ VP 確率が上がる（3 機会で 0.35〜0.95、確定扱いにならない）。
3. 買った当日／別カード使用済み／置ける道がない、では不当に増えない（街道:VP の比が不変）。
4. 傾向の混合は過信を抑える（混合 < 単一型）。
5. 複数購入後の使用で世代を決め打ちしない（両世代の仮説が 20% 以上残る）。
6. 保存則: 資源 19×5・発展 25（種類別）・VP ≤ 5・山の枚数・自分の手札の正確さを全粒子で、6 局の全出来事で検査。観測不整合 0。
7. 勝利判定の証拠は正しいタイミングだけ（他人の番で 10 点相当でも除外しない。手番が回って勝っていなければ除外）。
8. 当事者と第三者で盗みの扱いが違う（当事者は確定、第三者は枚数比）。

9（校正）と 10（正解ラベルの分離）は `catan v2-calib`（採点器）で実施。
