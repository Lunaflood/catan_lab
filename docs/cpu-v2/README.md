# カタン CPU v2 — 実装記録・実験結果・採否（2026-09-07）

設計書 [`docs/cpu-optimal-design.md`](../cpu-optimal-design.md) に従って、**未来の出目や相手の非公開情報を使わず、人間が知り得る情報だけから判断する** CPU を実装した。
M0〜M3 は完了、M4 は研究段階（小ゲームの検出器とロールアウト探索を実装したが製品には入れない）、M5〜M7 のうち M7 相当の凍結後評価は本書の「最終テスト」で実施。M5（学習）と M6（Worker 化・複数部屋の予算）は未着手。

## 何が変わったか（一言で）

旧 CPU は相手の手札を毎回一様に引き直していた。v2 は**公開の出来事（産出・建設・交易・独占の枚数・廃棄）から相手の資源を数え上げ**、盗みで割れた分だけを粒子で持つ（正解の手札に置いた確率 0.886）。発展カードは**購入世代と「使えたのに使わなかった」履歴**から隠れ勝利点の分布を出し（Brier 0.25、超幾何のみは 0.61）、**粒子ごとに「次の手番で 10 点に届くか」を通した勝利ハザード**で交易・盗賊・独占の判断を直す。

## 公平性（非干渉）

`crates/catan-ai/tests/fairness_v2.rs`: 相手の資源の分け方・発展の種類・山の内訳・本番 RNG を差し替えた双子で、観測・投影された出来事・予測・判断・説明が一致。相手方策（ロールアウト）も根の秘密を読まない（`small_games.rs`）。`cargo test --workspace --profile bench-debug` 全通過（デバッグ表明つき。粒子の観測不整合 0）。

**M0 で見つけて直した漏れ**: Web UI が第三者にも「盗んだ資源の種類」をアニメで見せていた（`last.stolen` を全席に配っていた）。当事者以外には `"HIDDEN"`（裏向きの札）に変更。

## 条件

- ルール `base-5th-2020/v1`（基本セット・10 点・持ち時間なし・400 手番で打ち切り = 未決着として分母に残す）。観測 `legacy_app`。
- 相手母集団: `v2_control`（設計書作成時の最高難易度 = 2 手読み・推定 3 通り）。**人間や Colonist の CPU に対する勝率ではない**。
- 4 人戦は 24 順列、3 人戦は 6 順列を巡回。seed は 1 局ごとに +1。

## 最終テストの事前登録（結果を見る前に決めた）

- 候補: `v2` 既定（分離粒子 256×2・期間つき q・傾向の混合・ハザード hazard_weight 20,000 / hazard_threat 3.0・推定サンプル 3・2 手読み）。バイナリ `target/catan_final.exe` sha256 `5b345094d867cbcd268e5d6dc54330f1fc19d7884daaa8677731dbc1989e4fe2`。
- 対照: `v2_control` × 3（4 人）、× 2（3 人）。途中で相手を更新しない。
- 局数: 4 人 4,800（480 局 × 10 ブロック、各ブロック 24 順列 × 20）、3 人 1,200（240 × 5）。固定 N、途中で止めない。
- 主指標: **全対局を分母にした勝率と Wilson 95% 区間**、未決着率。副指標: 平均手番、判断時間 p50/p95/max。
- 合格: 4 人の区間が 25.0% を含まず上側、3 人の区間が 33.3% を含まず上側、未決着率が対照の同型戦（0%）を上回らない、判断時間 p95 ≤ 30ms・max ≤ 1s、公平性テスト全通過。
- この結果を見て重みを変えたら、そのセットはもう最終テストではない（次は新しい未使用 seed）。

## 最終テストの結果

```
ファイル 5 / 対局 1200 / 決着 1200 / 未決着 0 / 平均手番 74.9
帰無仮説 33.3%（全対局を分母にした勝率と Wilson 95% 区間）
  v2                 457 / 1200   38.1%  [35.4, 40.9]
  v2_control         360 / 1200   30.0%  [27.5, 32.7]
  v2_control         383 / 1200   31.9%  [29.3, 34.6]
候補の判断時間（各ブロックの最大値）: p50 0.257ms / p95 4.557ms / max 174.0ms
```

区間は 33.3% を含まず上側。未決着 0。判断時間は基準内。生データ: `runs/final3p-*.txt`, `runs/final3p-summary.jsonl`。

### 4 人戦（v2 対 v2_control×3、4,800 局、seed 3000000〜3004799、10 ブロック × 480）

```
ファイル 10 / 対局 4800 / 決着 4800 / 未決着 0 / 平均手番 75.9
帰無仮説 25.0%（全対局を分母にした勝率と Wilson 95% 区間）
  v2                1601 / 4800   33.4%  [32.0, 34.7]
  v2_control        1047 / 4800   21.8%  [20.7, 23.0]
  v2_control        1034 / 4800   21.5%  [20.4, 22.7]
  v2_control        1118 / 4800   23.3%  [22.1, 24.5]
候補の判断時間（各ブロックの最大値）: p50 0.357ms / p95 6.358ms / max 178.7ms
```

ブロック別の v2 勝率: 35.6 / 33.1 / 35.6 / 32.3 / 33.5 / 32.9 / 34.6 / 34.0 / 30.4 / 31.5%（各 480 局、標準誤差 2.1〜2.2pt）。全ブロックで 25% を上回る。
区間は 25.0% を含まず上側。未決着 0（対照の同型戦・v2 の同型戦とも 0）。判断時間 p95 6.4ms ≤ 30ms、max 0.18s ≤ 1s。公平性テスト全通過。生データ: `runs/final4p-*.txt`, `runs/final4p-summary.jsonl`。

読み方: 対照 3 体を相手に**約 +8pt**（25% → 33.4%）。同じ対照に対する旧最高難易度（設計書作成時の max）自身は 25% 前後（同型）なので、v2 は旧最高難易度より強い。旧 CPU（1 手読み GreedyEval）×3 に対しては 240 局で 69.2%（候補選択用の走行）。**あらゆる相手に対する勝率ではない**。

## 採用／不採用

**採用**（2026-09-07）。`bot_for_level(3)`（さいきょう）を v2 に差し替えた。`v2_control` は CLI 名として残し、対照に使い続ける。

- 採用ゲート: 公平性／ルール違反 0（テスト）、事前登録の比較で勝率改善が支持された（4 人・3 人とも）、相手群（GreedyEval・baseline・同型）での退行なし、停止率 0、判断時間は予算内。
- 不採用（実験版として残す）: ロールアウト探索（`v2_roll*`）、hazard の重み・脅威係数・サンプル数の別値（差が誤差の範囲。既定のまま）。
- 配線: `crates/catan-ai/src/bots.rs::bot_for_level`。Web（`web/catan_wasm.wasm`）とサーバ（`catan-server`）は再ビルド済み（下記ハッシュ）。ブラウザでは全席のボットが出来事を受けるので、人間の席のボットも推定を更新するが使われない。
- Web の動作確認: `node docs/cpu-audit-20260907/smoke_wasm.mjs`（全席さいきょう = v2）3 人戦 4 局＋4 人戦 4 局、全局決着。判断 中央値 0.41ms / p95 9.0ms / max 115ms（このPCの Node 実測。ブラウザや別端末の保証値ではない）。
- 公開サイトへの push/deploy は**していない**。git commit もしていない（作業ツリーのまま）。

## 保証しないこと・限界

- 「常に最善手」「理論最強」ではない。手番内 2 手読み・推定サンプル 3・候補削減・近似したハザード（最長路は本数だけ、他人の手番の産出・交易は見ない）・手続き的な相手モデル。
- 相手モデル `q` は凍結した対照 CPU の対局で当てはめた値で、人間の値ではない。傾向の混合で過信を抑えているが、人間相手の校正は測っていない。
- 推定の弱点: 5 枚の勝利点が「長く持っている別の相手」に割り当てられ、他の保持者の VP 確率が押し下げられる型（校正の 0.0〜0.1 区間で実際 0.35）。
- 交易の候補生成は旧来の 180 通り（progressive widening 未実装）。相手どうしの交易・独占はハザードに入らない。
- オンラインの対不正性（サーバ権威方式）は範囲外。
- M4 のロールアウトは有害だった（27.1% / 21.5% 対 31.9%）。M5（学習）未着手。
- 公開サイトへの反映: **していない**（`web/catan_wasm.wasm` はローカルで再ビルド済み。採用時の配線は「結果」節に記す）。
