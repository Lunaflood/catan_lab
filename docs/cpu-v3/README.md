# CPU v3 — 手番内の手順探索（2026-09-10）

対象は `C:\catan_lab`。指定の `C:\catan\_lab` は存在せず、実際にカタンの
ソースがあるこのフォルダーを更新した。UI の既存変更は編集していない。

## 目的と変更

「いつでも理論上の最善手」を保証するものではない。現行最高難易度 v2 より
強い手順探索を作り、旧版と同じルール・席順条件で比較する。

- 新しい探索本体: `crates/catan-ai/src/turn_planner.rs`。
- `V2Config::v3()` / CLI の `v3` から利用。既存 v2 の観測・資源推定・隠れ VP 推定、
  勝利ハザード、初期配置は再利用する。`v2` と `v2_control` の設定は変更しない。
- 自分の手番内を最大 4 行動先まで読む。銀行交換→銀行交換→都市、
  街道建設カード→道→道→開拓地を一つの手順として採点する。
- 根では渡された全候補を確率平均で採点する。盗賊を最初から 3 候補に制限しない。
  道・開拓地・都市・海上交易・発展カード・盗賊はすべて追加探索の対象に残す。
- プレイヤー間交易は相手が受けるというモデルの下で、成立後の建設まで読む。
  複数の仮想交渉を連鎖させない。根の提案・対案は先行評価の上位 8 件を追加探索する。
- 深部では上位 3 手と各行動種類の最上位を残し、各兄弟に等しい予算を割り当てる。
  即時評価と深い評価の双方を残し、深い探索で良い短い手順を失わないようにする。
- 自分の得点だけでなく、最も進んだ相手の公開得点を評価する項を追加。
  最長交易路などを奪って相手の点を下げる効果を評価へ反映する。
- サイコロ、発展カード購入、盗みは結果を一つだけ引かず、各結果の確率で平均する。
  相手の手札は公開履歴からの推定 3 サンプルで平均する。

## 検証

事前の採用条件と未使用 seed は [registration.md](registration.md)。
初期の24局、開発用240局、最終検証の乱数は重複しない。
設定の比較探索や学習は行っていない。最終検証を見て重みは変更しない。

開発用: v3 対 v2×3、240局中76勝（31.7%）、未決着0。
これは最終検証とは分離した参考値。

最終検証（固定後の未使用乱数）:

| 対戦 | 勝数 / 全対局 | 勝率 | Wilson 95%区間 | 未決着 |
|---|---:|---:|---:|---:|
| v3 対 v2×3 | 324 / 960 | 33.75% | 30.83〜36.80% | 0 |
| v3 対 v2×2 | 173 / 480 | 36.04% | 31.87〜40.43% | 0 |

4人戦では25%を上回る改善が支持された。3人戦の区間には33.33%が含まれるため、
事前に定めた両形式の採用条件は満たさない。v3単体は最高難易度に昇格せず、
追加された初期配置・相手目線の要件を組み込む [v4](../cpu-v4/README.md) の比較用に残した。
最大判断時間は4人戦729.309ms、3人戦426.868ms。生ログ・集計は `runs/final*`。

テスト:

- `turn_planner.rs`: 銀行交換2回から都市で勝つ、街道建設から開拓地で勝つ、
  交易成立後の都市、全盗賊候補、列挙順による偏り、入力状態と本番乱数の非変更。
- `fairness_v2.rs`: 実際の公開イベント履歴を与えた双子の対局で、
  相手の資源・発展カード・本番乱数が違っても v3 の判断と説明が一致。
- ワークスペース全体の規則・保存則・推定・交渉テスト。
- 既存 `produce_real.rs` は履歴を必要とする v2 にイベントを渡さず探索を呼んでいた。
  そのため推定された手札が交易の承諾内容と一致せず、デバッグ表明で落ちていた。
  テストホストを実製品と同じ `notify_bots` に接続した。エンジンの交易規則は変更していない。


残りブロックの開始 seed と局数は registration を参照。
集計スクリプトは各120/240局の表示勝率から一意に決まる整数勝数を復元し、
全対局（未決着を含む）を分母に Wilson 95% 区間を計算する。
時間の p95 はブロック別 p95 の最大値であり、全判断を再集計した p95 ではない。

## 限界

- 最大4行動・候補削減あり。全ゲーム木の完全探索や均衡解ではない。
  初期配置は従来の評価のまま。相手の手番を詳細に先読みする探索・自己対戦学習は未実装。
- 採点値は勝率そのものではない。相手を妨害する価値も近似。
- 交易の承諾は予測であり、相手の承諾を保証しない。人間相手に校正したモデルではない。
- 「全候補」はゲーム側が生成した候補の意味。任意の資源束を使った全交渉や、
  ゲーム側で間引かれた廃棄をすべて網羅する意味ではない。
- 推定サンプルごとに手順を評価するため、将来も見えない秘密に依存する手順を
  楽観評価する余地は残る。情報集合を完全に扱う探索ではない。
- `max_nodes=60000` は追加探索の配分用の目安。先行採点と確率分岐を含む厳密な
  展開ノード上限でも、実時間の締切でもない。判断時間は実測値で報告する。
- 対 v2 の結果は、人間や外部サービスの CPU に対する勝率・世界最強の証明ではない。

v3単体は最高難易度には採用せず、追加要件を統合したv4を採用した。公開サイトへのpush/deployは行っていない。
