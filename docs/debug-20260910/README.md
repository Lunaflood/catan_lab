## 確認して修正した別の問題

- `web/colonist/catan_wasm.wasm` が旧版のままで、別画面とCPU・エンジンの版が違っていた。両方を再ビルド済みの同一ファイルへ更新し、ビルドスクリプトも両方へ配布するよう変更。WASMの読み込みで古いキャッシュを再利用しない。
- 交換条件が片側未指定の対案を、そのまま承諾して無償譲渡できた。両側が確定するまで承諾不可に修正。
- 1手番に256回以上の手動提案をすると提案カウンターが桁あふれした。加算を飽和させる（CPUの上限設定は変更しない）。
- 異常な資源枚数が整数変換で小さい値に変わる問題を入力時に拒否。エンジンの提案検証も各資源19枚以内に制限。
- オンラインの遅延・二重送信で、古い手番号が次の局面の別の手として実行され得た。送信時の局面指紋を着手前に確認し、不一致を拒否。負数・欠落の手番号も拒否。
- HTTPヘッダーの `content-length` が小文字だと本文を読まず、部屋への参加などが失敗した。大文字・小文字の違いを許容。
- 3人用の部屋に参加者が入ると、追加後の人数からCPU枠を計算して4人用に増えていた。参加前の卓人数を基準にCPUを置き換える。
