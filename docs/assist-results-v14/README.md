# v14 アシスト・対局結果

## 追加した操作

- 左上の設定の下に電球ボタン。「さいきょう」と同じ v4 AgentV2 で次の合法手を推奨する。
- 推奨手の名前、配置位置、理由、比較した候補を表示する。配置位置は黄色で強調し、「盤面で場所を確認」でパネルを閉じて確認できる。
- 建設では隣接資源・数字、平均産出、港を説明。道では連続した道の長さ、新たな開拓地候補数を説明。盗賊は妨害できる産出と自分への影響を示す。
- 理由は実際の選択手と観測できる事実・評価観点から生成する。探索全体の因果分解や最善手の数学的保証ではない。
- 操作は実行せず、自分が操作できる局面でのみ利用できる。局面変更時には古い推奨を無効化。閉じると計算を中止でき、30秒で打ち切って再試行を案内する。
- オンラインでは受信済みの着手もアシスト用履歴に記録する。部屋の鍵などはWorkerへ渡さない。

## 結果の見方

- 出目2〜12の実際の回数と理論上の期待回数、数値表を表示する。
- 初期配置〜決着までの各手番の最終勝利点を折れ線で表示する。伏せた勝利点カードは決着後のみ含めて公開する。
- 最長交易路・最大騎士力の移動による点数減少も記録する。スライダーで各時点の全員の点数を確認できる。
- 順位・推移・出目の移動ボタンを設置。小さい画面では結果カード内をスクロールできる。
- 履歴はエンジンの全着手経路で収集するため、保存局面の再現・オンライン再接続でも再構築される。対局終了前の result_json は null で、相手の伏せた点数を返さない。

## アシストの隔離

Web Worker内の別WASMで開始条件と着手履歴を再現し、元の盤面の指紋と一致する場合だけ助言を返す。助言者は独立した推論用乱数と観測履歴を使う。相手の未公開カードや未来の出目は観測へ渡さない。本体の乱数・CPU・着手記録は助言の計算によって変更されない。
