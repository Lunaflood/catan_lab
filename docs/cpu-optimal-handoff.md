`C:\catan_lab\docs\cpu-optimal-design.md` を全文読み、この設計に従って公平なカタンCPU v2を実装してください。

ユーザーの目的は、未来の出目や相手の非公開情報を使わず、人間が知り得る情報から最善の判断を目指すCPUです。特に、発展カードを長く使わず保持している履歴から、隠れた勝利点を確率的に推測し、終盤の脅威・交易・盗賊の判断へ反映したいと考えています。

現在はその保持履歴に基づく推定が未実装です。残りカード構成をランダム再配分する処理と、2手読み・推定3通りのCPUがあるだけなので、実装済みと誤認しないでください。

最初に現行作業ツリーを確認して比較用CPUを固定してください。未コミット変更も含めて保存し、既存UI・オンライン機能・Colonist調査ファイルを壊さないでください。このプロジェクトを他の暗号資産・競艇・スロット関係のメモリと混ぜないでください。

設計書のM0から順に進め、まずM3までを完了してください。

1. 人間とCPUの情報公開契約を固定する。特に銀行残数・廃棄内訳・盗み・送信前の対案草稿を確認する。
2. 席別の観測イベントと、購入世代・使用機会を含む履歴を実装する。
3. 保存則を満たす資源/発展の推定を作る。長期未使用をVP確定にせず、相手の温存傾向も考慮する。
4. 隠れVPの分布と、相手が次の手番で勝つ危険を判断へ組み込む。
5. 非公開情報を変えても入力・予測・判断が変わらないテスト、推定の校正、固定旧CPUとの比較を行う。

M3完了後は成果を記録してM4以降へ進んでください。大規模自己対戦やニューラルネット導入を先行させず、情報集合の制約と小ゲームでの正確性を先に確認してください。

研究段階で改善しない変更は製品へ昇格させず、実験版として残してください。常に最善手・理論最強という未証明の主張はしないでください。各段階の完了と全工程の完了を区別し、対戦相手・試合数・生の勝敗・未決着・95%区間・処理時間を報告してください。

最終成果物にはコード、実行コマンド、テスト、実験結果、採用/不採用理由、残る限界を含めてください。公開サイトへの反映状況も明記してください。
